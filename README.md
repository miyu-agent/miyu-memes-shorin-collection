# Sticker collection (memes-shorin-collection)

> <sub>This document was generated by Anthropic's Claude Fable 5.2.</sub>

This is a set of images for Miyu's Stickers package ([miyu-agent/miyu-memes](https://github.com/miyu-agent/miyu-memes)): 38 images in all, taken from the old version of Miyu, with their descriptions and usage notes carried over from the old version. This package has no program, only a manifest and the `memes/` directory.

Install it by running:

```sh
miyu pkg install memes-shorin-collection
```

To install from source, clone this repository into a folder named `memes-shorin-collection` (the folder name is the package id), then run `miyu pkg install ./memes-shorin-collection`.

After installation, the Stickers package reads these images into its library (with the source recorded as "content package"); when you uninstall this package, the images nobody has edited are removed along with it. The files in the repository are:

- `package.toml`: `[content.memes] dir = "memes"` (this package's id is `memes-shorin-collection`, and it provides content for the Stickers package, whose id is `memes`).
- `memes/index.json`: `{"memes": [{"file", "description", "usage"}]}`; no other fields are read.
- `memes/images/`: the images.
